> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add FFF text search and make its main picker keys similar to the user's installed Snacks picker.

**Architecture:** Keep FFF's own UI and use its supported configuration. Keep Snacks for non-FFF sources and as an all-files grep fallback. Do not install an adapter or modify plugin source.

**Tech Stack:** AstroNvim 6, lazy.nvim, Lua, dmtrKovalenko/fff, Snacks.

## Task 1: Configure supported shared keys

Modify lua/plugins/fff.lua. Preserve lazy_sync=true, home scanning disabled, debug disabled, existing build hook.
Add:
```lua
prompt_vim_mode = true,
keymaps = {
  move_down = { '<Down>', '<C-n>', '<C-j>' },
  move_up = { '<Up>', '<C-p>', '<C-k>' },
  preview_scroll_up = '<C-b>',
  preview_scroll_down = '<C-f>',
},
```
Add Ctrl-C cancel through supported extra mappings only after verifying the installed picker close API or supported close key array behavior. Do not guess internal functions.
Keep Enter, Ctrl-S/V/T, history Ctrl-Up/Down, Ctrl-Q unchanged.
Keep native FFF Tab selection behavior and Shift-Tab grep-mode cycling; explicitly explain that these are not identical to Snacks. Do not implement a full Snacks compatibility layer. Ctrl-U/D are not promised as Snacks list-page movement; do not silently bind them to preview scrolling after moving preview actions to Ctrl-B/F.
Help remains :help fff.nvim, not an invented ? popup.
Verify normal-mode navigation in actual FFF input; add j/k/q normal-mode extra mappings only if absent and implementable through confirmed APIs. Never map j/k in insert mode.

## Task 2: Add grep entry points

Modify lua/plugins/astrocore.lua inside opts mapping construction:
```lua
maps.n['<Leader>fw'] = { function() require('fff').live_grep() end, desc = 'Find words (FFF)' }
maps.n['<Leader>fc'] = { function() require('fff').live_grep_under_cursor() end, desc = 'Find word under cursor (FFF)' }
maps.x['<Leader>fc'] = { function() require('fff').live_grep_under_cursor() end, desc = 'Find selected text (FFF)' }
maps.n['<Leader>ff'] = { function() require('picker_resume').resume() end, desc = 'Resume last picker' }
```
Preserve Space fW as Snacks all-files grep. Preserve all AST, diagnostic, Git and other bindings. Confirm FFF resume exists in the installed revision before applying. Document that Space ff will no longer resume Snacks sources; retain Snacks resume through :lua Snacks.picker.resume().

## Trade-offs

No custom help popup, select-all, hidden/ignored toggles, list paging emulation, or layout toggles in this scope. FFF plain/regex/fuzzy modes differ from Snacks regex toggle. Test first-use behavior and terminal key delivery; do not promise performance improvements without measurements.
